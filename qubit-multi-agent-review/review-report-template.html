What severities and categories meanWas Schweregrade und Kategorien bedeuten
Blocker
Must be resolved; it {{blockerHoldsEn}}. A defect that can be triggered in live use (the change fails at what it promises, or an unhandled case gives a wrong result), a security hole, worse code health (breaks an ADR or a boundary, inverts a dependency, adds a second mechanism or needless complexity, breaks an invariant, leaves a test failing), or a new feature without any test.Muss gelöst werden; {{blockerHoldsDe}}. Ein im Live-Betrieb auslösbarer Defekt (die Änderung verfehlt, was sie verspricht, oder ein unbehandelter Fall liefert ein falsches Ergebnis), eine Sicherheitslücke, schlechtere Codequalität (bricht ein ADR oder eine Grenze, kehrt eine Abhängigkeit um, fügt einen zweiten Mechanismus oder unnötige Komplexität hinzu, bricht eine Invariante, lässt einen Test fehlschlagen) oder ein neues Feature ohne jeden Test.
Optional
Can be left out; the author decides. A change {{changesInEn}} to behaviour, tests or structure without a failure in live use, e.g. a missing test case.Kann entfallen; der Autor entscheidet. Eine Änderung {{changesInDe}} an Verhalten, Tests oder Struktur ohne Fehler im Live-Betrieb, z. B. ein fehlender Testfall.
Nit
Like Optional, wording only: names, comments, docs.Wie Optional, nur Formulierung: Namen, Kommentare, Doku.
FYI
Nothing to change {{changesInEn}}; worth a follow-up ticket.Nichts zu ändern {{changesInDe}}; ein Folgeticket wert.
